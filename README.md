# 立直麻将点数计算（Riichi Mahjong Scorer）

一个简洁美观的安卓端立直麻将番数与和牌点数计算应用。输入庄闲、和牌方式、牌型与宝牌/里宝牌指示牌，自动判定番型、计算番数、符数与和牌点数。

## 功能

- **和牌条件输入**：亲家/子家、荣和/自摸、场风/自风、立直/双立直/一发、天和/地和（亲家必为东家，自风自动锁定为东；子家自风只能是南/西/北）
- **特殊和牌方式**：枪杠和、海底捞月、河底摸鱼（仅凭牌型无法判定，需用户勾选；自动与荣和/自摸及天和/地和互斥校验）
- **牌型输入**：点选牌山构建手牌（14 张），可添加副露（顺子/刻子/明杠/暗杠），点击手牌标记和牌张
- **宝牌输入**：表宝牌指示牌（最多 4 张）；里宝牌仅在立直/双立直时可添加并计入
- **自动判定**：全部常用番型 + 役满（含双倍役满、累计役满开关）
- **输出**：番型列表、合计番数、符数、点数（荣和/自摸分别展示支付方式）

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- 核心算分引擎为纯 Kotlin JVM 模块（`core`），与 UI 分离，可独立单元测试
- Gradle 8.4 / AGP 8.2.2 / Kotlin 1.9.22 / compileSdk 34 / minSdk 24

## 构建与运行

1. 用 Android Studio（Hedgehog 或更新版本）打开本项目目录。
2. 等待 Gradle 同步完成（首次会下载依赖）。
3. 连接安卓设备或启动模拟器，运行 `app` 模块即可。

命令行构建（需 JDK 17 与 Android SDK；命令行构建需在 `local.properties` 配置 `sdk.dir` 或设置 `ANDROID_HOME`，Android Studio 打开工程时会自动生成）：

```bash
# 运行核心引擎单元测试
./gradlew :core:test

# 构建调试 APK（需 Android SDK）
./gradlew :app:assembleDebug
```

## 使用方法

1. 选择亲家/子家、荣和/自摸、场风、自风，按需勾选立直/双立直/一发、天和/地和。
2. 若和牌属于特殊牌局状况，勾选「枪杠和」（仅荣和）、「海底捞月」（仅自摸）或「河底摸鱼」（仅荣和）。
3. 从牌山点击添加手牌（共 14 张，含和牌张）；点「＋ 添加副露」录入副露；点击手牌切换和牌张（金色标记）。
4. 添加表宝牌指示牌；里宝牌需先勾选立直/双立直才可添加。
5. 点「计算点数」查看番型、番数、符数与点数。

## 规则说明

- 采用一般规则 + 天凤式可选规则（均可关闭）：
  - **累计役满**：13 番以上按役满计算（关闭则按三倍满封顶）
  - **双倍役满**：四暗刻单骑、国士无双十三面、纯正九莲宝灯按双倍役满计算
- 平和自摸 20 符；七对子固定 25 符；连风牌雀头 4 符。
- 役满手牌不再累加普通番型与宝牌。
- 暗杠不影响门前清；荣和完成的刻子按明刻算符（三暗刻判定按暗刻）。
- **特殊和牌**：枪杠和/海底捞月/河底摸鱼各 1 番；枪杠时和牌张在手牌中只能有 1 张（其余 3 张在他人加杠中），且枪杠与河底、海底与天和/地和互斥。
- **输入校验**：手牌/副露张数不符（无杠 14 张、每杠 +1）、无任何番型（无役，宝牌不计作番型）、非和牌型、单牌超过 4 张、宝牌/里宝牌指示牌与手牌合计超过每种 4 张（指示牌与手牌出自同一副 136 张牌）、亲家自风非东/子家自风为东、立直非门前清、特殊和牌方式与荣和/自摸矛盾等非法输入均会提示错误，不会强行计算。

## 算法验证

`verify/` 目录包含与 Kotlin 引擎逐行对应的 Node.js 镜像实现及 66 项断言用例（已知点数表、番型组合、役满、宝牌/累计役满、特殊和牌、非法输入校验），全部通过；Kotlin 侧 `:core:test` 的 60 个单元测试亦全部通过，且 `:app:assembleDebug` / `:app:assembleRelease` 已验证可完整打包 APK：

```bash
# 运行核心引擎单元测试
./gradlew :core:test

# 构建调试 APK（需 Android SDK）
./gradlew :app:assembleDebug

# 运行 Node.js 镜像验证
cd verify && node test.mjs
```
